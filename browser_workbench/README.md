# 团队日历工作台（浏览器版）

直接访问：<https://vilyvivi-sv.github.io/team-calendar/browser_workbench/>

本页面可由 GitHub Pages 直接打开，不需要安装 Node.js、运行命令窗口或连接电脑文件。日历事项保存在当前浏览器的本地存储中；GitHub Pages 只托管网页程序，不接收日历事项。

## 使用方式

- 在电脑浏览器中添加、修改、拖动和删除事项，并导出当前月份或自选日期范围的 PNG 长图。
- 手机适合查看日程；长图可以转发给团队成员。
- “下载 JSON 备份”可备份当前浏览器的日历；“恢复 JSON”会用所选备份替换当前浏览器中的日历。
- 更换设备或浏览器后，选择备份文件恢复。不同设备之间不会自动同步。
- 清除浏览器网站数据会删除本地日历，请先下载 JSON 备份。

此目录不包含任何日历事项数据。团队成员需要查看安排时，请分享导出的 PNG；不要把 JSON 备份发布到公开仓库。
